# README #

# Depois de clonar #

* Rodar `yarn install`
* Rodar `build`

Caso esteja usando Mac, verificar se após o build ele criou corretamente a pasta target.
A estrutura correta para as imagens é target/dist/images. Caso outras pastas dentro de images
tenham sido criadas, mover as imagens svg diretamante para images e apagar todo o restante.

* Rodar `start`
* Para build e start automático rodar `dev`
